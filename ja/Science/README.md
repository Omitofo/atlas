# 科学（かがく / kagaku）

アトラス（あとらす / atorasu）の中で最も大きく発展したセクション（せくしょん / sekushon）。

科学の原則は伝統的な学問分野で整理されていますが、多くの原則は境界を越えます（特に熱力学、情報、進化）。

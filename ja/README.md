# Atlas（アトラス / Atorasu）

深い理解（ふかい りかい / fukai rikai）、長期的な定着（ちょうきてきな ていちゃく / chōkiteki na teichaku）、継続的な成長（けいぞくてきな せいちょう / keizokuteki na seichō）のために設計された**生きた原則の保管庫（いきている げんそくの ほかんこ / ikite iru gensoku no hokan-ko）**。

このリポジトリは **Obsidian**（ローカルグラフ / rōkaru gurafu）と **GitHub**（読みやすい相対Markdownリンク / yomiyasui sōtai Markdown rinku）の両方に最適化されています。

> **焦点（しょうてん / shōten）**：*原則（げんそく / gensoku）*のみ — 世界の仕組みを説明する根本的な規則、法則、生成的なアイデア。百科事典的な知識ではありません。

## 使い方（つかいかた / tsukaikata）

### Obsidianで
1. このリポジトリをクローンまたはダウンロードする
2. `ja` フォルダ（またはvaultのルート）をvaultとして開く
3. グラフビューとバックリンクを有効にする
4. 新しい原則を追加するときは `_templates/Principle.md` のテンプレートを使う

### GitHubで
すべてのリンクは相対Markdownリンクなので、GitHub上で直接機能します。

## このVaultの中心哲学（このぼーるとの ちゅうしんてつがく / kono bōruto no chūshin tetsugaku）

1. **一つの原則 = 一つのノート**
2. すべてのノートが同じ豊かな構造に従う（定義 → ファインマン → 比喩 → 例 → 関係）
3. 原則間の明示的なリンクは第一級の市民である
4. 構造は大規模な再編成なしに何十年も成長できるように設計されている
5. カバー範囲より深さと明確さを優先する

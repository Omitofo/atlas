# Atlas

Un **coffre de principes vivant** conçu pour une compréhension profonde, une rétention à long terme et une croissance continue.

Ce dépôt est optimisé à la fois pour **Obsidian** (graphe local) et pour **GitHub** (liens Markdown relatifs lisibles).

> **Focus** : Uniquement des *principes* — règles fondamentales, lois et idées génératives qui expliquent comment le monde fonctionne. Pas de connaissance encyclopédique.

## Comment l’utiliser

### Dans Obsidian
1. Clonez ou téléchargez ce dépôt
2. Ouvrez le dossier `fr` (ou la racine du vault) comme vault
3. Activez la vue graphique et les backlinks
4. Utilisez le modèle dans `_templates/Principle.md` pour ajouter de nouveaux principes

### Sur GitHub
Tous les liens sont des liens Markdown relatifs pour fonctionner directement sur GitHub.

## Philosophie centrale de ce Vault

1. **Un principe = une note**
2. Chaque note suit la même structure riche (définition → Feynman → métaphores → exemples → relations)
3. Les liens explicites entre principes sont des citoyens de première classe
4. La structure est conçue pour grandir pendant des décennies sans réorganisation majeure
5. Préférer la profondeur et la clarté à la couverture

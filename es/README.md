# Atlas

Un **vault vivo de principios** diseñado para la comprensión profunda, la retención a largo plazo y el crecimiento continuo.

Este repositorio está optimizado tanto para **Obsidian** (grafo local) como para **GitHub** (enlaces Markdown relativos legibles).

> **Enfoque**: Solo *principios* — reglas fundamentales, leyes e ideas generativas que explican cómo funciona el mundo. No conocimiento enciclopédico.

## Cómo usarlo

### En Obsidian
1. Clona o descarga este repositorio
2. Abre la carpeta `es` (o la raíz del vault) como vault
3. Activa la vista de grafo y los backlinks
4. Usa la plantilla en `_templates/Principle.md` al añadir nuevos principios

### En GitHub
Todos los enlaces son Markdown relativos para que funcionen directamente en GitHub.

## Filosofía central de este Vault

1. **Un principio = una nota**
2. Cada nota sigue la misma estructura rica (definición → Feynman → metáforas → ejemplos → relaciones)
3. Los enlaces explícitos entre principios son ciudadanos de primera clase
4. La estructura está diseñada para crecer durante décadas sin reorganizaciones mayores
5. Preferir profundidad y claridad sobre cobertura
